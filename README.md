# KochApp Updates

Öffentlicher Update-Kanal für die private KochApp.

Dieses Repository enthält ausschließlich die jeweils aktuelle APK und die zugehörige `version.json` als GitHub Release. Der eigentliche Quellcode der App bleibt im privaten Repository.

Die App prüft nur dann auf Updates, wenn in den Einstellungen ausdrücklich auf **„Nach Update suchen“** getippt wird.
